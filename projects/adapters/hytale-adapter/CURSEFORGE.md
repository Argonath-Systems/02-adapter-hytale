# Hytale Adapter

## Summary
Compatibility layer bridging the Core Lib with the Hytale Server API.

## Metadata
- **Class**: Mods
- **Main Category**: API and Library
- **Additional Categories**: Server Utility

## Description
The bridge between LordOfTheTales frameworks and the Hytale engine. Handles packet interception and event translation.

### Key Features
* **Feature Rich**: Built with extensibility and performance in mind.
* **Integrated**: Seamlessly works with other LordOfTheTales modules.
* **Configurable**: extensively configurable to suit your server's needs.

### Installation
1. Download the `.jar` file from the Files tab.
2. Place it in your server's `mods` or `plugins` folder.
3. Restart the server.

### Dependencies
* **Core Lib**: Required for all modules.
* Check the file description for other specific dependencies.
